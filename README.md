# Homem-Aranha

Site estático sobre o Homem-Aranha, feito só com HTML e CSS para o Trabalho Avaliativo 01 de Desenvolvimento Web I (IFC Campus Concórdia).

## Páginas

- `index.html`: início
- `personagem.html`: poderes e inimigos
- `historia.html`: origem do herói
- `curiosidades.html`: curiosidades

O estilo de todas as páginas está em `style.css`.
